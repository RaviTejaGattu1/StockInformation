# Python Finance Info

A web-based Python app to retrieve stock information using Yahoo Finance API.

## Setup
1. Clone: `git clone https://github.com/your-username/Python-Finance-Info.git`
2. Create venv: `python3 -m venv venv`
3. Activate: `source venv/bin/activate`
4. Install: `pip install -r requirements.txt`
5. Run: `python3 app.py`

## Features
- Enter stock symbol to get company name, price, and changes.
- Error handling for invalid symbols and no network.
